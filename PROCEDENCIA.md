# Procedencia

Práctica basada en el código oficial de Google, rama `repo-starter`, commit `ba9470a`, del repositorio https://github.com/google-developer-training/basic-android-kotlin-compose-training-mars-photos.

El código original conserva su licencia Apache 2.0. Los commits posteriores registran la incorporación del punto de partida, la capa de datos, la inyección manual de dependencias, la configuración de compilación y las pruebas.
